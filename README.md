# BridalLive Helper

A Chrome side panel that sits **beside** [BridalLive](https://app.bridallive.com) so staff can look up inventory, add a new size or color, and print labels without leaving the sale or receiving screen.

BridalLive itself is unchanged. Chrome shrinks the page and shows the Helper next to it.

## Open the Helper

1. Open **https://app.bridallive.com** and sign in.
2. Click the purple **BL** button on the page, or the **BridalLive Helper** icon in the Chrome toolbar.

You need **Chrome 141 or newer**.

First-time install: see [Set up the Helper](docs/SETUP.md).

## What you can do

- **Inventory** — Search every connected location. Add another size or color from an existing item. On a sale, add a found item to the open order.
- **Labels** — Print Avery 5160 labels from a receiving voucher, a spreadsheet (Mass Labeling), or reprint one item.
- **Settings** — Connect each boutique, pick text size, and choose which inventory columns you see.

Until a store is connected in Settings, Inventory uses a sample catalog so you can still learn the screens.
